# ✈️ SkyWings - Responsive Travel Website

A modern, fully responsive **Travel Landing Page** built using **HTML5, CSS3, and JavaScript**. The website provides an attractive and user-friendly interface for showcasing travel destinations, travel services, customer testimonials, and booking information.

Designed with a **mobile-first approach**, this project delivers a seamless browsing experience across desktops, tablets, and smartphones.



## 🚀 Features

- Modern and responsive UI
- Fully mobile-friendly layout
- Beautiful Hero Section
- Popular Destinations Section
- Travel Services
- Customer Testimonials
- Interactive Navigation Menu
- Smooth Scrolling
- Clean Animations
- Cross-browser Compatibility
- Optimized Layout

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts
- Remix Icons

## 🌍 Deployment

This project is deployed using **Vercel**.

### Deploy on Vercel

1. Push the project to GitHub.
2. Login to Vercel.
3. Import the GitHub repository.
4. Click **Deploy**.
5. Your live website will be generated automatically.
